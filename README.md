# Continuous Elevator Sync

A Satisfactory mod for servers that run the **Continuous Elevator** (Keep Feeding To Maintain Phase) mod. It makes
the elevator consume its parts on factory time instead of world time, so a slow server no longer starves it.
Only the server needs it.

- Player-facing text: [Docs/Release/FullDescription.md](Docs/Release/FullDescription.md)
- How it works: [Docs/Architecture.md](Docs/Architecture.md)
- Changes: [Docs/Release/Changelog.md](Docs/Release/Changelog.md)

Package: `Tools\BuildScripts\package-continuouselevatorsync.bat [local]` in the modding workspace.
